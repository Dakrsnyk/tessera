# Client brief (Ardane, translated summary of the user's French brief — every point is a requirement)

1. Start over on creative quality. The previous ad was too basic (flat phone + title on cream, generic slides, tiny
   unreadable UI, stutter). Analyse what made it amateur and design a far more ambitious direction. Apple / Nike /
   big-tech level. Mainly motion design + the REAL Ardane interface + sophisticated animation + a female English
   voice-over. Ardane must feel like a new way to manage life's essentials, not « an app that shows widgets ».
   Grab attention immediately, impress visually, make people want to download.
2. Strong, coherent, recognisable visual identity. Cinematic edit with controlled rhythm (dynamic vs contemplative),
   elegant kinetic typography, fluid transitions, precise virtual camera moves, depth compositions with several
   layers, foreground elements, parallax; crafted phone animation (controlled rotations, camera push-ins, angle
   changes, transitions between screens); lighting, reflections, shadows and depth consistent with the real UI;
   modern, minimal, tech, premium. Immersive soundtrack: original or fitting music, controlled bass, SFX synced to
   animation. AVOID: standard transitions, plain zooms on screenshots, text appearing without staging, generic ad
   templates, animation without artistic intent. Every transition must tell something or reveal a feature.
3. Central concept: Ardane's interface comes alive. The phone is a staging element, not a stand. Example: phone
   appears in a dark elegant space, camera pushes into the screen showing Ardane's home; when a feature is presented,
   its widget comes OUT of the phone into the foreground in a depth composition, grows smoothly until perfectly
   readable while the phone stays visible behind; the widget can expand, reveal its information and show how it
   works; a fluid transition brings it back into the phone; the camera moves on. Use this principle intelligently with
   creative variations (no repetition). When the VO explains a feature, its UI must be visually highlighted — the
   viewer must never have to decipher a tiny phone screen. Phone, widget and animations answer each other in space.
   Technically clean, fluid, spectacular without excess.
4. Main film ~45–60 s, English narration, built on real features. Suggested structure (improve it if possible):
   S1 Hook (dark space, phone appears, elegant UI, widgets come alive, music subtle then rising, female VO introduces
   the idea that life's daily essentials deserve an interface designed around you; no long/generic intro).
   S2 An interface that looks like you (home + personalisation; several widgets come out of the phone and organise /
   evolve visually; a continuous motion-design sequence showing several wallpapers / universes at once — light, dark,
   colourful, minimal, space… only styles really available — moving, overlapping, aligning, transforming; NOT a static
   one-by-one gallery; widgets adopt styles consistent with each universe).
   S3 Fitness, an experience beyond the widget (phone, a big Fitness widget emerges; session tracking and set counter;
   rest time and workout progress; exercise library; the exercise demonstration animations — real app extracts in
   motion, highlight characters, equipment and movement mechanics with reframing and camera moves).
   S4 The Lock Screen: act instantly (one of the most striking moments: locked iPhone close-up, the Lock Screen becomes
   the starting point of a motion composition; Fitness info/animations compatible with Lock Screen / Live Activities:
   set counter, rest, progress. Then a transition to food scanning ONLY via a path that really exists).
   S5 Nutrition: understand what you eat (different staging from Fitness: a food, then the iPhone, the scan through
   the real UI; the Nutrition widget comes out and takes the foreground; calories / protein / carbs / fat in a readable
   animated composition from real captures; then nutrition widgets; simplicity, precision, fluidity).
   S6 Money, Planning and other essentials (faster than Fitness/Nutrition, each with an identifiable staging; Money
   widget comes out and reveals its data; then Planning, Habits, other relevant mini-apps; show breadth without a
   feature catalogue).
   S7 Final reveal (widgets gather around the phone — Fitness, Nutrition, Planning, Money, personalisation — position
   harmoniously in space, then merge back into the phone into a clean final composition; music peaks, then logo +
   English call to action; message: Ardane brings together and personalises daily essentials in an interface that
   belongs to the user; memorable, elegant, strong).
5. Female English VO, professional, natural, confident, modern, slightly cinematic, neutral American; not artificial
   or over-enthusiastic; pacing fitted to the edit, let visuals breathe; key lines synced to visual reveals; concise,
   memorable, emotional ad writing; tells the idea, does not describe the screen. Deliver the full English script with
   timings, pauses, voice intentions and scene mapping; generate it with a voice tool if available.
6. FLUIDITY IS A TECHNICAL PRIORITY: constant frame rate, smooth animation, no stutter, no frozen/repeated frames, no
   skipping transitions; interpolation only when it really helps; check after export; clean sync of VO, music,
   animation. Vertical 1080×1920 at 60 fps preferred if truly smooth. Never pretend 60 fps fixes bad sources: rebuild.
   Check bitrate, encoding quality, text sharpness, UI readability on a phone.
7. Truly different ads per duration/platform (not cut-downs): Main 45–60 s; 30 s (more direct narration, strongest
   moments, clear personalisation + Fitness + Nutrition); 15 s (ONE idea, immediate hook, quick visual demo; don't
   cram); 6–10 s (one visual reveal + short CTA); Fitness (energetic: training, set counter, exercise animations, Lock
   Screen); Nutrition (brighter, precise: scan, macros, quick access); Personalisation (wallpaper transformation,
   styles, widgets coming out of the phone, building a personal interface). 9:16 first (TikTok, Reels, Shorts); other
   ratios if useful, recomposed.
8. Absolute fidelity to the real app: real captures/elements only; never approximate screens with a video generator;
   motion design may add depth, reflections, graphics, transitions but must not fake how Ardane works; data coherent,
   interactions plausible, only available features; unimplemented features must not be shown as working.
9. Use all relevant skills/tools/agents for real; if a tool is unavailable, use the best feasible alternative and state
   limits; never claim a tool was used or a result exists when it doesn't.
10. Deliver real final video files: main film, variants, final English VO + timed script, motion elements / sources,
   platform exports, short recap of files and what remains for external software. Watch exports fully and check:
   fluidity, UI quality/readability/fidelity, edit/VO/music coherence, no distortions/wrong text, format fit. Fix before
   delivering. Final priority: one exceptional, perfectly smooth, visually accomplished ad beats several ordinary ones.
