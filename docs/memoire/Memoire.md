# Mémoire du projet

Ce que Claude Code doit savoir d'une session à l'autre, et ce que tu veux lui dire. Claude lit ces notes au début de chaque tâche et les met à jour à la fin (consigne dans `CLAUDE.md`). Tu peux les lire et les modifier dans n'importe quel éditeur (Obsidian, VS Code, Bloc-notes) : pousse tes modifications avec GitHub Desktop (Commit puis Push) pour que Claude les voie.

- [[Demandes]] : ta boîte à idées et à tâches, écrite par toi, lue par Claude.
- [[Chantiers]] : ce qui est en cours, en pause, et où en est chaque chantier.
- [[Decisions]] : les choix déjà faits (à ne pas remettre en question sans raison).
- [[Pieges-connus]] : les erreurs déjà rencontrées et comment les éviter.
- État détaillé de l'app : [HANDOFF.md](../../../HANDOFF.md) · Règles de travail : [CLAUDE.md](../../../CLAUDE.md)
- La carte du code : [[Ardane]]
