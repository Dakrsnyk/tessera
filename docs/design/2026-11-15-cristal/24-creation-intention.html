Parcours 4 · Création par intention — taille d'abord

Nouveau départ imposé : la place à donner (taille), puis ce qu'on veut suivre (la catégorie, dite comme une intention), puis les informations, présentées par la question à laquelle elles répondent. Ardane remplit déjà les emplacements avec une proposition tirée de tes données ; on ajuste. Ensuite, ce que la stratégie garde : Ardane recompose seul et le dit, trois dispositions sans glisser, une ambiance puis le Studio si on veut plus.

Le principe

On dit ce qu'on veut voir

Après la taille, on parle d'intentions et de questions, pas de widgets. Ardane remplit les emplacements avec une proposition tirée de tes données ; on ajuste, et Ardane recompose seul en disant pourquoi. Aucun glisser.

Pour qui : la personne qui débute, ou qui veut un résultat juste sans réfléchir à la mise en page.

Le parcours en clair

Combien de touchers

Petit : Petit, « Suivre mon entraînement », une question = 3 touchers ; enregistrer = 4.

Moyen à 2 : Moyen, l'intention, « Continuer » (la proposition convient) = 3 touchers ; enregistrer = 4. À ajuster : +1 toucher par échange.

Grand à 3 : Grand, l'intention, « Continuer » = 3 touchers ; enregistrer = 4.

Où vit chaque fonction existante

Rien n'est supprimé

  • Tailles : page 1 ; écran verrouillé : lien en bas de la page 1.
  • Tous les widgets : la liste des questions de chaque catégorie.
  • Thème, Style, Couleurs, Fond, Bordure, Graphique, Densité, Mes styles : « Tout personnaliser dans le Studio ».
  • Photos et citations : une catégorie (« Revoir mes souvenirs »), puis son éditeur.
  • Premium : cadenas ; « Débloquer et enregistrer ».
Limites dites clairement

Ce qui ne se fait pas

  • Plusieurs widgets séparés d'un coup : retiré de Créer.
  • Une intention = une catégorie : on ne mélange pas deux catégories dans un widget.
  • La proposition « avec tes données » demande d'écrire le choix (À développer) ; aujourd'hui l'app a une composition fixe par espace.
  • Pas de widget météo (À développer). iOS ne laisse aucune app poser un widget.
Vérifié dans le code

Ce qui existe, ce qui change

  • Existe : un seul widget réuni (Composer, ComboLayout), compositions de départ par espace (SpaceCatalog.preset : petit, paire Moyen, trio Grand), refus rédigés.
  • À changer : l'ordre ; « Créer les N widgets séparés » ; le « + » qui change la taille seul.
  • À écrire : page Taille, intentions, questions, carte des emplacements, proposition tirée des données.
