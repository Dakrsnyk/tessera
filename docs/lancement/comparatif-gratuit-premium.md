# Ardane : gratuit ou Premium

Tableau relevé dans le code le 2026-11-16 (commit `84590b6`), chiffres comptés dans les catalogues de l'app. À refaire si un catalogue change.

**Règle de base :** sans Premium, rien de ce que tu notes n'est effacé ni bloqué. Les données sont gardées, et ce qui est réservé à Premium s'affiche dès que tu l'achètes. Si Premium s'arrête, tes choix restent enregistrés : la couleur de l'app repasse à Saphir, et l'icône déjà en place ne change pas.
